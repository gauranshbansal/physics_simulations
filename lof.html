About the Mathematical Model

This simulator iterates a damped Newton map for f(z) = z³ + (α - 1)z - β, with an optional complex periodic forcing term. When γ = 0, the colored regions are classical Newton basins for the exact cubic roots. When γ > 0, the forcing makes the map time-dependent, so yellow marks points that did not settle near a root within the iteration limit.
